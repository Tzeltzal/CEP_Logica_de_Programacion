## Estructura de un Programa y Pseudocódigo

La estructura de un programa *sin importar el lenguaje* en el que se escriba, está compuesta por tres partes esenciales.

- Entrada de datos
- Algoritmo
- Impresión de resultados
    
    <aside>
    🛠
    
    La base de un programa son las palabras reservadas.
    
    </aside>

### Variables y Tipos de datos

<aside>
🛠

Una variable es un contenedor que almacena datos de forma temporal en la memoria de un prograna.

Cáracter. Una o varias letras, procesados como texto. ‘entre comillas simples’

Entero. Valor númerico sin punto decimal.

Real. Datos con punto decimal.

Lógico. Solo es V o F.
