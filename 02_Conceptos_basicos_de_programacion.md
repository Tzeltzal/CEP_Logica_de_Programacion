# Conceptos básicos de programación

- **Lenguaje de programación:** Idioma artificial creado para indicar a la PC las tareas a ejecutar, que posee una *sintaxís* y *semántica* propias de cada lenguaje.

- **Sintaxís:** Reglas de escritura propias como símbolos y palabras clave reservadas.

- **Semántica:** Interpretación interna.

| Sintaxís | Semántica |
|----------|-----------|
| main() | Instrucción valida |

- **Programa:** Bloque de instrucciones (código fuente) escrito en un lenguaje especifico.

> Para ejecutar un programa la computadora traduce del código fuente a lenguaje máquina a traves de dos medios: **compilador** e **interpréte**.

- **Interpréte:** Ejecuta el código línea por línea.

- **Compilador:** Toma todo el bloque de código y lo ejecuta una sola vez.
