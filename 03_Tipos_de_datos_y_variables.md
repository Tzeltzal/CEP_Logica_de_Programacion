# Tipos de datos y variables

| Tipos de datos | Uso | Ejemplo |
|----------------|-----|---------|
|**int** | Almacena valores númericos | int edad = 45; |
| **float** | Almacena valores decimales | float medida = 54.5; |
| **char** | Almacena valores de tipo cáracter | char = 'a' |
| **string** | Almacena cadenas de caracteres | string = "Hola mundo!" |

El **ámbito de una variable**, se refiere a la **visibilidad** de una variable dentro de un programa y pueden ser **globales** y **locales**
